Upload Guide

YouTube Shorts

  1. Open YouTube Studio app on phone
  2. Tap Create -> Upload
  3. Pick video from Google Drive (synced via rclone)
  4. Paste title from dashboard (use Copy button)
  5. Paste description and tags
  6. Set thumbnail (download from Drive _thumbnails folder)
  7. Publish
  8. Mark as Posted in Upload tab

TikTok (mobile only)

  1. Open TikTok app on phone
  2. Tap + to create new video
  3. Upload from gallery (sync from Drive first)
  4. Add caption from dashboard
  5. Post
  6. Mark as Posted

Instagram Reels

  1. Open Instagram app
  2. Tap + -> Reel
  3. Pick video from gallery
  4. Add caption + hashtags
  5. Share
  6. Mark as Posted

Facebook Reels

  1. Open Facebook
  2. Create -> Reel
  3. Upload video
  4. Paste caption
  5. Share
  6. Mark as Posted

Tips

  • Use Drive sync to get files on phone
  • Always copy captions from dashboard - they have correct hashtags
  • Mark each platform as you post to track progress
  • Cleanup old workspaces weekly to save disk space
